怎么用

  • 查人：在搜索框输入姓名、学号、英文名，或任何履历内容（例如「冠军」「新生营」），列表即时筛选。点任一行打开完整履历，按年份分组。
  • 排序：点表头即可排序，例如按「服务时数」「获奖」从高到低。
  • 对比：勾选最左边的方格（最多 4 人），底部出现「对比」按钮，可并排比较。
  • 按年份看：「全部年份」下拉可只统计某一年（如只看高三 2026）。
  • 更新资料：用 Individual's Utmost Achievement Calculator.exe（或 python app.py）打开时，网页会自动载入 Result 文件夹的最新内容：新增、修改或删除履历表后几秒内自动更新；「计入 / 不计」的调整也会自动存进 成就奖_手动调整.json。「导出离线版」得到的单一 HTML 文件内容固定在导出当时。

数字怎么算

  • 服务时数：优先采用学生自己填写的「总服务时数」；该年没填总数时，才把校内、校外服务每一项的时数相加（小时、分钟、如「50M」的写法都认得）。被规则排除或手动设为不计的服务项，会从中扣除它的时数。两种算法相差超过 1 小时时，个人页会一并列出供对照。
  • 获奖：比赛条目中出现名次或奖项字眼（冠军、金奖、优秀奖、第X名、特优、佳作等）即计为获奖，属自动识别，个别可能有误，请以履历原文为准（★ 标示）。
  • 执委/职务：按手册统一写法。标准职称：主席、秘书、事务（「事物」同）、财政（正/副）、查账、总学长（正/副）、助理总学长、执委、会员；其它职位写成「执委(XXX,XXX)」（计入其中的职位个数）。主席、秘书、事务、财政、总学长没写正/副的当作「正」。合唱团「音乐主席」、二十四节令鼓队的队长类与执委主席同级，写成「主席(正/副)」。童军等「分团」职位（队长类除外）算「会员」。「监督XX主席」「督导XXX主席」属于活动筹委，计入筹委。助理类、授课人类（含助教、小教练、教官）、队长类（含正/副队长、分团的总队长/小队长等，节令鼓队长除外）、监督/督导/顾问/教练/领队类、首席/组长/领养人类（如副弹拨首席、扬琴组长、扬琴组领养人、声部组长）、家族职位（如家族家长）、联课组别（如联课组别第六组）、校内服务负责人（「校内服务负责人：A、B」拆开，每项各算 1 个）从执委/会员分开，另计「中层管理」（中层管理数＝不同中层管理职位的个数，不算进职务数）。联课处工委等归入执委(…)。写在执委栏的活动筹委职位（如「《弈德杯》筹委主席」）和「校内服务负责人」移到筹委。感恩聚会不算学会活动，相关条目全部不计。运动会、田径赛的职位/筹委（如「运动会主席」「监督运动会服务主席」）算服务筹委团，计入筹委（班级名义的除外）；学会在运动会上的义卖不计，演出和服务照算；高三毕联会 / 高三年级组的职位和筹委（含编辑工委会、广告工委会、教师节工委会）属于年级，不计（相关服务、活动照算）。会员不计职务数，同年已有其它职位时不另列会员。★ 特别标记：联课处工委、文娱工委、XXX志工工委、国际交流筹委/负责人会用金色 ★ 标出（名单、个人页、Excel 都有），只做标记，不改变计分。 每一年的原文都保留在个人页里，方便核对。
  • 计分规则（不计的条目在个人页以灰色划线显示并注明原因，所有数字都不含它们）：
    1. 以班级为单位的内容、服务、活动、比赛不计（条目含「班级、班际、班长、班会、康乐委员」等；运动会写生、号码布设计、短片制作比赛也属班级活动）。但以学会身份筹办班级赛的「筹委」「团内工作」照算（例如合唱团筹办班级歌曲合唱比赛）。
    2. 只计 A、C、D、E 类；B 类（体育、学术培训队）整年不计。
    3. 同一年同一比赛同时写在两个学会时只计一次，保留与比赛相关的学会（例如舞蹈比赛保留在舞蹈团）。
    4. 比赛必须代表本学会：比赛内容与所属学会无关（例如舞蹈团学生写个人武术比赛、数学比赛）不计。按学会关键词自动判断；判断不了的标「待确认」，暂时计入。
    自动判断有误时，在个人页点条目右边的「计入 / 不计」即可修改，改动存在这台电脑的浏览器里；用「导出手动调整」可以存成文件交给其他老师导入。
  • 同一学号有多个文件时，采用内容最多的一份，其他文件名列在个人页底部。

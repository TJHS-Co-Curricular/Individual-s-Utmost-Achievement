# 高三最高成就奖 · 计分规则（已确认）

资料来源：`Result/`（学生履历表 xlsx/pdf）
工具：本文件夹的 Flask 本地网站（结构仿 AttendanceViewer：`app.py` + `achievement/` + `templates/` + `static/` + `scripts/build_exe.bat`），打包名「Individual's Utmost Achievement Calculator.exe」

- 运行 `python app.py` 或 exe → 浏览器自动打开，自动载入 Result 最新内容（每 3 秒检查变动）
- 执委 / 职务的归类（执委、主席级、中层管理、会员、移到筹委、不计、特别标记）由 `config/member_rules.json` 决定，改那个文件即可（exe 版放在 exe 旁边的 `config/` 文件夹会优先采用）
- 比赛的规则（算不算获奖、是不是代表本学会）由 `config/award.json` 决定
- 其它规则（服务时数、B 类、双学会重复等）在 `achievement/rules.py`（网页端即时重算在 `static/core.js`，职务合并逻辑两边要一致）；手动调整存 `data/成就奖_手动调整.json`；导出在 `output/`，日志在 `logs/app.log`（项目结构见 `CLAUDE.md` / `README.md`）
- 可下载 Excel（总表 / 明细 / 计分规则）、导出离线版单一 HTML；个人页有「简单 / 详细」切换
- 供上级校对的文档：「成就奖系统：筹委与执委/职务的判定定义（供校对）」（同名 .docx）

## 执委/职务（按手册，上级 2026-09-24 校对）

- 标准职称：主席、秘书、事务（「事物」「总务」同一等级，一律写成「事务」，已确认）、财政（正/副）、查账（不分正副，已确认）、总学长（正/副）、助理总学长、执委、会员（队长、副队长改列「中层管理」，见下）
- 其它职位一律写成「执委(XXX,XXX)」
- 已确认：组长不算队长（组长现归中层管理）；助理类不算标准职称；监督 / 督导类不算主席；联课处工委归入执委(…) 并计入职务数
- 上级定（最新）：助理类、授课人类（含助教、小教练、教官/副教）、队长类（正/副队长、分团总队长、小队长 / 中队长 / 分队长等；节令鼓队长仍算主席）、监督 / 督导 / 顾问 / 教练 / 领队类、首席 / 组长 / 领养人类（上级点名：副弹拨首席、扬琴组长、扬琴组领养人；系统同样套用到声部组长、小组组长、各组组长、XX组领养人等）、家族职位（上级点名：家族家长、「家族家长（小组组长）」；系统同样套用到家族卫生、家族团康、家族族长）、联课组别（上级点名：联课组别第六组）、校内服务负责人（上级点名；「校内服务负责人：新春快闪、运动会开幕及闭幕仪式演出」拆开，每项服务各算 1 个），从执委 / 会员里分开，另建统计「中层管理」：中层管理数＝该年不同中层管理职位的个数，不算进职务数；一条里同时有中层管理和其它职位（如「正课程+小教练」「主席助理兼正纪律」）时拆开各自计算

- 上级定（最新）：「校内服务负责人」（XX服务负责人）属于筹委，写在执委栏的也移到筹委计算
- 上级定（最新）：「监督XX主席」「督导XXX主席」属于活动筹委，移到筹委计算（页面标「原写在执委栏」）；一格里连写「执委主席监督成果汇报主席监督…主席」的会拆开，执委主席照算职务

## 计入范围

0. 上级定：教师节相关的「校内服务」不计（服务时数一并扣除）；其它栏目里的教师节条目照原规则
0. 上级定：感恩聚会不算学会活动，各栏相关条目（筹委、服务、团内工作等）全部不计，服务时数一并扣除
1. 以班级为单位的内容、服务、活动、比赛不计（班级身份参赛、班级表演、班级赛服务、班级监督等；含「心动不如Sing动」「开启你的Music Show」等班级歌曲比赛；上级定：「运动会写生比赛」「运动会号码布设计比赛」「运动会短片制作比赛」也属班级活动）
2. 学会的筹委照算（例：合唱团筹办班级歌曲合唱比赛的票务股）；团内工作中的班级赛工作人员也照算
3. 只计 A、C、D、E 类；B 类（体育、学术培训队）整年不计
4. 同年同一比赛写在两个学会 → 只计一次，保留与比赛相关的学会（例：舞蹈&口才 → 只算舞蹈）
5. 比赛须代表本学会；与所属学会无关的个人比赛不计（例：舞蹈团学生的武术比赛）。按学会关键词自动判断，判断不了的标「待确认」暂时计入，可在页面手动改

## 服务时数

优先采用学生自填的「总服务时数」；该年没填总数才用逐项相加（上级 2026-09-24 定：曾试过只用逐项相加，但对没逐项写时数的学生不公平，已改回）。被排除的服务条目会扣除其时数。运动会服务时数、毕联会相关服务照算。

## 获奖

比赛条目含名次 / 奖项字眼（冠军、金奖、优秀奖、第X名、特优、佳作等）即计为获奖（自动识别，★ 标示）。

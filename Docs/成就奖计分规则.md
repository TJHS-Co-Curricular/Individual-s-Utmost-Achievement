## 执委/职务（按手册，上级 2026-09-24 校对）

- 标准职称：主席、秘书、事务（「事物」同，已确认）、财政（正/副）、查账（不分正副，已确认）、总学长（正/副）、助理总学长、执委、会员、队长、副队长
- 其它职位一律写成「执委(XXX,XXX)」
- 已确认：组长不算队长；助理类不算标准职称；监督 / 督导类不算主席；联课处工委、小教练、助教等中层管理归入执委(…) 并计入职务数
- 上级定（做法 A）：主席 / 秘书 / 事务 / 财政 / 总学长没写正/副 → 当作「正」（这些都是学会执委，不是筹委团），计入职务数
- 上级定（最新）：童军等「分团」职位（含分团总队长、分团小队的队长）、监督 / 督导 / 顾问 / 教练 / 领队类（小教练除外）、小队长 / 中队长 / 分队长，一律算「会员」（不计职务数）
- 上级定：合唱团「音乐主席」、二十四节令鼓队的队长类，等级与执委主席相同，写成「主席(正/副)」
- 上级修正：写在执委栏、但为某个活动而组成的筹委团职位（如「《弈德杯》筹委主席」「欢送会正主席」「开放日-负责人」）移到筹委计算，不计职务数；页面标「原写在执委栏」
- 监督 / 督导 / 顾问 / 教练 / 领队类写在筹委栏的也移到执委栏（页面标「原写在筹委栏」），并按上面的规定算「会员」
- 上级定（最新）：运动会、田径赛的筹委 / 职位（如「全国独中田径锦标赛筹委主席股」「监督运动会服务主席」「运动会主席」）算「服务筹委团」，计入筹委、不计职务数；写在执委栏的也移到筹委（页面标「原写在执委栏」）；以班级名义的（如「班级运动会义卖活动负责人」）仍不计
- 上级定（最新）：学会在运动会上的义卖不计（执委、筹委、团内工作、服务各栏都不计，服务时数一并扣除）；学会在运动会上的演出、表演和服务照算（都属联课团体内）；运动会服务时数照算
- 上级修正：高三毕联会（毕业班联合会）的职位与筹委属于年级，不属于学会，不计执委也不计筹委（如「高三毕联会广告工委」「毕业班联合会之谢师宴筹委正秘书」「毕联会：教师节活动副主席」）；一条里同时写了学会职位和毕联会职位时，只把毕联会那部分划掉；毕联会相关的服务时数、活动照算（上级纠正：如高中毕业典礼服务、高三欢送会工作属于服务，可以算）
- 上级确认：会员不计职务数；同年已有其它职位时不另列会员
- 上级定：联课处工委、文娱工委、XXX志工工委、国际交流筹委/负责人（条目含「国际…交流」且写在筹委栏，或写明筹委/负责人）要「特别标记」——名单、个人页（简单/详细）、Excel、CSV 都用金色 ★ 标出，可勾「只看 ★ 特别标记」筛选；只做标记，不改变计分
- 尚待上级回复：执委(A,B) 算 2；筹委每条计 1 项

## 计入范围

1. 以班级为单位的内容、服务、活动、比赛不计（班级身份参赛、班级表演、班级赛服务、班级监督等；含「心动不如Sing动」「开启你的Music Show」等班级歌曲比赛；上级定：「运动会写生比赛」「运动会号码布设计比赛」「运动会短片制作比赛」也属班级活动）
2. 学会的筹委照算（例：合唱团筹办班级歌曲合唱比赛的票务股）；团内工作中的班级赛工作人员也照算
3. 只计 A、C、D、E 类；B 类（体育、学术培训队）整年不计
4. 同年同一比赛写在两个学会 → 只计一次，保留与比赛相关的学会（例：舞蹈&口才 → 只算舞蹈）
5. 比赛须代表本学会；与所属学会无关的个人比赛不计（例：舞蹈团学生的武术比赛）。按学会关键词自动判断，判断不了的标「待确认」暂时计入，可在页面手动改

## 服务时数

优先采用学生自填的「总服务时数」；该年没填总数才用逐项相加（上级 2026-09-24 定：曾试过只用逐项相加，但对没逐项写时数的学生不公平，已改回）。被排除的服务条目会扣除其时数。运动会服务时数、毕联会相关服务照算。

## 获奖

比赛条目含名次 / 奖项字眼（冠军、金奖、优秀奖、第X名、特优、佳作等）即计为获奖（自动识别，★ 标示）。
